# obsidian-vault

Deployed with Vercel.

## Development

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy to production
vercel --prod
```

## Structure

- `public/` - Static HTML/CSS/JS files
- `docs/` - Documentation and Markdown
- `src/` - Source code (if applicable)
