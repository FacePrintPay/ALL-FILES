# AnarSec — Tails (Amnesic & Incognito Live System)

**Purpose:** Threat-model–aligned operational guidance for using Tails as an amnesic, Tor-enforced live OS.  
**Scope:** Documentation & doctrine only. Tails runs externally (USB/DVD/SD). Not executed inside this stack.

## Core Properties
- Live System (external boot)
- Amnesic by default
- Tor-enforced networking
- Minimal, audited environment

## Threat Model
Tails mitigates network-level and host-forensic risks but does not protect against compromised hardware, firmware, or human error.
