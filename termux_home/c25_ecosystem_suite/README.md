# 🌌 Constellation25 — Full-Stack Ecosystem

This suite integrates all discovered code files, scripts, and documentation into a unified, interactive local web application and REST API backend.

## 🚀 Quick Start
1. Run dependencies: `pip install flask`
2. Start the backend server: `python3 app.py`
3. Open your browser or Termux viewer at: `http://localhost:5000`
